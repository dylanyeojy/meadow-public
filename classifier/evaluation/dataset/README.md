# Synthetic student journal dataset (RQ1)

100 fictional private journal entries, written to read like students at Malaysian universities, for evaluating how well the fine-tuned MentalBERT classifier (`ourafla/mental-health-bert-finetuned`) reads journal-style text. The protocol is Section 3.7 of the project proposal.

**Frozen on 20 October 2026.** `dataset.jsonl` is never edited. The RQ1 results always describe exactly these entries.

## At a glance

| | |
| --- | --- |
| Entries | 100: 25 each of Normal, Anxiety, Depression, Suicidal |
| Language | English, with Malaysian context from the content, not from slang or code-switching |
| Length | 52 to 334 words (median 141.5); 66 to 431 MentalBERT tokens (median 173) |
| Over the 128-token window | 64 of 100, so the classifier's chunking is exercised |
| Generated by | Claude Sonnet 5.5 (`claude-sonnet-5-5`), effort `high`, one independent request per entry through the Batch API, 16 and 20 October 2026 |
| Generation cost | About US$0.47 for all 102 generations |

## How the entries were made

Every entry comes from one cell of a generation matrix (`../generation/matrix.json`):

- **5 stressors:** exam pressure, coursework load, finances, family, and social isolation and relationships. Each lists good, neutral and bad events.
- **3 personas:** a reserved local second-year, a sociable local final-year, and a first-year international student.
- **3 writing styles**, which also set the length: brief (30 to 70 words), reflective (80 to 150) and long (200 to 350).

Each class draws 25 different cells, with every stressor exactly 5 times per class, from seed `20261016`. The script picks one event per entry. The Suicidal class never draws a positive event; the other three draw from all of them, so a Normal entry can be about bad news and a Depression entry about good news. The class sets the emotional tone, not the topic.

| | Brief | Reflective | Long | Positive event | Neutral event | Negative event |
| --- | --- | --- | --- | --- | --- | --- |
| All classes | 36 | 33 | 31 | 22 | 19 | 59 |

The prompts are one shared system prompt and one template per class (`../generation/prompts/`). Each entry records a fingerprint of the exact prompts used: system `b1c0df8d9e8f`; normal `00d9c189c96e`, anxiety `45fa8029bb2c`, depression `5b8d9686cae8`, suicidal `73c06d805e8d`. The prompts forbid label words such as "depressed" or "suicidal", and forbid any method or plan detail in Suicidal entries.

## How the labels were checked

**Blind review by the author.** Every entry was labelled from its text alone, shuffled, under an anonymous item number, without its intended class in view. An entry passed only if the label matched its intended class and it read as plausible student writing that could not be classified from a single word. 100 of the first 102 blind labels matched. The two that did not (one Depression and one Suicidal entry, both read as Normal) were regenerated with the same matrix cell and passed on the second attempt. An earlier AI screen of the first round was set aside and not used.

**Second raters.** An independent rater labels 20 entries, 5 per class, without seeing the intended labels, and Cohen's Kappa measures the agreement. The bar, κ ≥ 0.60, was set before any rating.

| Rater | Entries | κ | Raw agreement | Result file |
| --- | --- | --- | --- | --- |
| Rater 1 | 20 | 0.67 | 15 of 20 | `../results/second-rater-agreement.json` |
| Rater 2, after a calibration session | 20 different entries | 0.87 | 18 of 20 | `../results/second-rater-2-agreement.json` |

Both raters' disagreements concentrate in Depression: 3 of rater 1's 5 Depression entries were read as Anxiety or Normal, and rater 2's two disagreements were both Depression entries read as Normal. Rater 2 did not read every entry in full: the calibration session taught them to scan for each class's cue phrases, and calibration and rating together took about 3 minutes. The author's own relabelling of rater 1's 20 entries is kept separately in `../results/author-relabel-agreement.json`. It is not an inter-rater measure.

## Fields in `dataset.jsonl`

| Field | Meaning |
| --- | --- |
| `id` | Entry id, such as `anxiety-07` |
| `label` | The intended class: `normal`, `anxiety`, `depression` or `suicidal` |
| `text` | The journal entry |
| `words`, `tokens` | Word count, and token count under MentalBERT's tokenizer without special tokens |
| `over_window` | Whether `tokens` exceeds 126, the 128-token window less the two special tokens |
| `stressor`, `persona`, `style`, `event`, `valence` | The matrix cell and event the entry was written from |
| `attempt` | 1, or 2 for an entry regenerated after review |
| `model`, `system_prompt`, `class_prompt`, `seed` | What produced it, for reproducing the run |

## Limitations

- **Synthetic.** The entries are written by a language model to depict each class, not taken from real students, so they test the classifier on the target kind of text without fully reproducing real journalling.
- **One generating model.** Every entry comes from Claude Sonnet 5.5. The zero-shot baseline is a GPT model, so it is not tested on its own family's text, but the entries may still share one model's habits.
- **Clean class boundaries.** Each prompt keeps its class distinct, for example no thoughts of death outside Suicidal. Real writing overlaps more, so this test is somewhat easier than real use.
- **Small.** 25 entries per class gives wide confidence intervals, especially for Suicidal recall.
- **Labels reflect the author's design.** The second raters exist to check them.
- **Classes may be separable on surface wording.** Rater 2 agreed on 18 of 20 by scanning for cue phrases rather than reading in full, even though the review screened out entries classifiable from a single word. A classifier may likewise succeed on cues that real journalling would not always contain.
